عالم الرقميات والبرمجة

دليل دورات الإعلام الآلي والبرمجة – FBIB

كتالوج شامل وموزع حسب المجالات التقنية لمنحك المهارات الأكثر طلباً في سوق العمل الحديث

1. المكتبية والمهارات الرقمية

  • Maîtrise du Pack Office (Word, Excel, PowerPoint, Access)
  • Excel avancé (TCD, Macros, VBA)
  • Introduction à l'informatique & maintenance PC
  • Certification internationale ICDL/PCIE

2. البرمجة والتطوير

  • Algorithmique et logique de programmation
  • Python (Data, Automatisation, Scripting)
  • Java (POO et Développement d'applications)
  • C / C++
  • PHP & MySQL (Backend)
  • JavaScript moderne (ES6+)

3. تطوير المواقع والويب

  • Front-End (HTML5, CSS3, JavaScript)
  • Frameworks (React.js / Vue.js)
  • Développement Full-Stack (MERN / MEAN)
  • WordPress (Création et gestion)
  • Back-End (Node.js / Django / Laravel)

4. تطوير تطبيقات الجوال

  • Android Développement (Kotlin / Java)
  • Multiplateforme (Flutter / React Native)

5. قواعد البيانات والبيانات

  • Gestion de bases de données (SQL, MySQL, PostgreSQL)
  • Analyse de données (Excel, Power BI)
  • Data Science avec Python (Pandas, NumPy)
  • Machine Learning & Intelligence Artificielle

6. الشبكات والأمن والأنظمة

  • Administration réseaux (TCP/IP, Cisco CCNA)
  • Administration systèmes (Windows Server / Linux)
  • Cybersécurité — Fondamentaux & Bonnes pratiques
  • Cloud Computing (AWS / Azure)

7. التصميم والوسائط المتعددة

  • Infographie (Photoshop, Illustrator)
  • Montage vidéo (Premiere Pro / DaVinci Resolve)
  • UI/UX Design (Figma)
  • Motion Design (After Effects)

8. إدارة المشاريع البرمجية

  • Méthodologies Agile / Scrum
  • Introduction à la gestion de projets IT
